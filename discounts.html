Android

Инструкция для Android

  1. Откройте сайт nafnafiki.ru в браузере Chrome
  2. Нажмите ⋮ (три точки) в правом верхнем углу
  3. Выберите «Добавить на главный экран»
  4. Подтвердите — иконка NAF NAFIKI появится на рабочем столе
iPhone

Инструкция для iOS

  1. Откройте сайт nafnafiki.ru в браузере Safari
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
  3. Выберите «На экран “Домой”»
  4. Нажмите «Добавить» — готово!
