## 🚫 ТЕСТОВЫЕ ЛЕНДИНГИ — НЕ ПУБЛИКОВАТЬ И НЕ ИНДЕКСИРОВАТЬ

Папка **`тестовые лендинги/`** содержит **черновики лендингов, НЕ готовые к публикации**.

| Файл | Тема | Статус |
|---|---|---|
| `den-rozhdeniya.html` | День рождения под ключ | 🟡 черновик, на проработке у владельца |
| `pennaya-vecherinka.html` | Пенная вечеринка | 🟡 черновик, на проработке у владельца |
| `soap-bubbles.html` | Шоу мыльных пузырей | 🟡 черновик, на проработке у владельца |

### Что это значит для ИИ и разработчика

1. **НЕ публиковать** эти страницы: не добавлять в меню, кнопки, тексты, sitemap.xml, футеры и любые другие видимые места основных страниц.
2. **НЕ удалять** эти файлы и **не переименовывать** папку — владелец дорабатывает их и вернёт к публикации позже.
3. **НЕ добавлять** ссылки на них из других файлов (кроме документов внутри самой папки).
4. **НЕ включать** эти страницы в sitemap.xml и **не снимать** запреты из robots.txt / meta-тегов noindex, пока владелец явно не попросит.
5. **НЕ переносить** файлы из этой папки в корень сайта без явной просьбы владельца.
6. Страницы внутри папки **уже помечены** `<meta name="robots" content="noindex, nofollow">` — сохраняй этот тег при редактировании.
7. Страницы в папке могут **устаревать** относительно основных (модалки, цены, стили). Считай их снапшотами: не синхронизируй автоматически, не «исправляй расхождения» без запроса.
8. Пути внутри черновиков переписаны с префиксом `../` (`../css/style.css`, `../index.html`, `data-images="../images/…"`), чтобы страницы открывались и предпросматривались прямо из папки. **Не «исправляй» эти префиксы** и помни: при переносе в корень их нужно убрать (см. шаг 2 ниже).

### Как вернуть лендинг в публикацию (когда владелец попросит)

1. Переместить файл из `тестовые лендинги/` в корень сайта.
2. Убрать префиксы `../` из всех `href`, `src`, `onclick="window.location.href='…'"` и `data-images`.
3. Убрать `<meta name="robots" content="noindex, nofollow">` из `<head>`.
4. Обновить `<link rel="canonical">` (путь в корне) и og:url.
5. Добавить страницу в `sitemap.xml`.
6. Добавить ссылки в меню (`<nav class="desktop-nav">`) основных страниц и при необходимости — в блоки «С чем часто заказывают».
7. Убрать запрет папки черновиков из robots.txt (строка `Disallow: /%D1%82…` в каждой группе `User-agent`) — только percent-encoding, кириллицу Яндекс.Вебмастер считает недопустимым символом.
8. Обновить этот файл (AI-CONTEXT.md): перенести страницу из таблицы «черновики» в «опубликованные».

## 🔧 Технические правила проекта

1. **Кодировка:** UTF-8 без BOM. Все файлы — UTF-8. Не сохраняй с BOM.
2. **Навигация:** шапка с меню копируется на всех страницах; при добавлении нового пункта — обновляй **все** основные HTML-файлы (кроме служебных папок).
3. **Модалки и скрипты:** блоки `contact-modal-overlay`, `orderModal`, `serviceModal`, `successModal`, `mobile-bottom-nav`, копи-кнопка и `toggleSeoText()` обязательны на страницах с карточками услуг — бери за образец файл из корня, а не из черновиков.
4. **Метрика:** Яндекс.Метрика (id 109547647) должна присутствовать в `<head>` каждой публичной страницы.
5. **SEO-поля страницы:** `title`, `meta description`, `canonical`, OG-теги, Twitter-теги, `geo.region`/`geo.placename` — обязательны.
6. **Изображения:** WebP, атрибуты `alt` с ключевыми словами, `loading="lazy"` (кроме hero).
7. **Цены** сверяй с `yandex_market.yml` и пакетами на главной — они там эталонные.
